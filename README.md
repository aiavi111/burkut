# Bürküt — демо-магазин одежды

Сайт-магазин уличной одежды из Бишкека: главный экран с логотипом, который при прокрутке садится в шапку, каталог, страница товара, корзина с оформлением заказа, поиск, профиль и контакты. Анимации повторяют рилс с Shopify-шаблоном: пиксельный переход между страницами, фото товара листаются вбок по движению курсора, параллакс, плавный скролл.

Это демо: заказы, оплата, SMS и формы никуда не отправляются.

## Как открыть
Открой `index.html` в браузере или подключи репозиторий к Vercel / GitHub Pages — сборка не нужна.

## Как править
- Тексты, цены и товары — в `src.html`, массив `PRODUCTS`.
- После правок запусти `./build.sh` — он пересоберёт `index.html`.
- Фото лежат в `img/`.
